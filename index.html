Drive Sync Info

Personal Google Drive backup & sync utility / 個人雲端硬碟備份同步工具

關於本工具（繁體中文）

這是帳號擁有者個人使用的雲端硬碟備份／同步工具，建立在開放原始碼軟體 rclone 之上。它只在帳號擁有者本人的電腦上執行，用來把本人的 Google 雲端硬碟檔案備份到本機、或在本機與雲端之間同步。本工具僅供本人使用，不對外提供服務、不開放註冊、也沒有其他使用者。本頁存在的目的，是為了向 Google 說明這個私人用途的應用程式；詳細的資料處理方式請見隱私權政策。

About this tool (English)

This is a personal cloud-storage backup and sync utility used solely by the account owner, built on the open-source tool rclone. It runs only on the account owner's own computer, to back up that same owner's Google Drive files locally and to keep local and cloud copies in sync. The tool is for the owner's personal use only: it is not offered as a service, has no sign-up, and has no other users. This page exists to describe that private-use application to Google; for details on how data is handled, see the Privacy Policy.
